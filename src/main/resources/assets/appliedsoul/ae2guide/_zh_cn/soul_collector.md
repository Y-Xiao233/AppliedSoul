# 灵魂收集器

<Row gap="16">
    <BlockImage id="appliedsoul:soul_collector" scale="2" />
</Row>

**灵魂收集器** 可以收集所在区块中所有 **灵魂激光基座** 中的灵魂, 并将其直接存入 **ME网络中**

---

你可以使用 **<ItemLink id ="appliedsoul:range_card" />** 来增加其工作范围, 最大工作半径为 **3个区块**
