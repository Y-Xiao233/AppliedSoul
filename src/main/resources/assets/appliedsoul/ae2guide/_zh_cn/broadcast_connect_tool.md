# 灵魂广播器连接工具

<Row gap="16">
    <BlockImage id="appliedsoul:broadcast_connect_tool" scale="2" />
</Row>

**灵魂广播器连接工具** 可以用来设置 **<ItemLink id ="appliedsoul:soul_broadcast" />**

* 1.你首先需要使用 **灵魂广播器连接工具** **SHIFT+右键** 来选中某个 **<ItemLink id ="appliedsoul:soul_broadcast" />**
* 2.然后对任何可被加速的机器按下 **SHIFT+右键** 这个机器就可以正常被加速
* ps1.默认为 **4(工业先锋: 灵魂涌动的配置)** * **8(所有面默认生效)** 倍速
* ps2.该装置 **无法** 跨纬度加速机器
* ps3.被其他 **<ItemLink id ="appliedsoul:soul_broadcast" />** 选中的机器 **无法再次被选中**
* ps4.被选中的机器也 **无法** 再通过管道加速
* ps5.手持该工具会 **高亮显示相关方块** **红色代表被其他灵魂广播器选中** 绿色代表灵魂广播其 **黄色代表该灵魂广播器下已经被选中的机器**
